# 给你的信 · IcebearMailbox 💌

一个装满手写信的静态小信箱：牛皮纸信封、火漆封印、复古邮票与邮戳。
点按火漆，看她拆开你写下的每一封信。

纯 HTML + CSS + 原生 JavaScript，零依赖、零构建，双击即用。

## 本地预览

最简单：**双击 `index.html`**。

或者起个本地服务（更接近部署后的效果）：

```bash
cd IcebearMailbox
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 小提示：如果你改了 `css/style.css` 或 `js/` 里的文件，记得把 `index.html` 里
> 对应的 `?v=3` 版本号 +1（比如改成 `?v=4`），再刷新页面，避免浏览器用旧缓存。

## 加一封新信（三步）

1. **手写信拍照 / 扫描**，放进 `letters/` 下按日期新建的文件夹，多页按顺序命名：
   ```
   letters/2026-09-01/1.jpg
   letters/2026-09-01/2.jpg
   ```
2. 打开 **`data/letters.js`**，在 `letters` 数组**最上面**加一条：
   ```js
   {
     id: "2026-09-01",
     date: "2026-09-01",
     title: "写给秋天的你",
     excerpt: "关于最近的一些小事。",
     pages: ["letters/2026-09-01/1.jpg", "letters/2026-09-01/2.jpg"]
   },
   ```
3. 刷新页面，信箱里就多了一封新的信 ✉

> 项目自带的 `letters/demo/` 是两张示例信纸，放进真信后可以删掉对应的条目和文件夹。

## 配置项（都在 data/letters.js）

| 配置 | 说明 |
| --- | --- |
| `siteTitle` | 页面大标题（也会变成浏览器标签标题） |
| `subtitle` | 标题下的一行小字 |
| `footerText` | 页脚的小落款 |
| `startDate` | 在一起的日子 `"YYYY-MM-DD"`，页面会显示「在一起第 N 天」；不设置则显示一句提醒 |
| `letters[].theme` | 信件主题「皮肤」，可选。目前支持 `"qixi"`（七夕星河：紫金配色、银河、牛郎织女剪影、鹊桥喜鹊、金色火漆双子星封印、七夕限定邮票邮戳）。读这封信时整站换装，合上即换回；最新一封信的主题决定首页皮肤。不写 = 经典暖阳信笺风 |

## 拍照 / 扫描小建议

- 光线均匀的白天自然光最好，避免阴影和反光
- 手写纸铺平、镜头正对，避免透视变形
- 长边 1600–2000px、JPEG 质量 75–80% 足够清晰，加载也快（手机上看更明显）
- 一页一图，按阅读顺序命名

## 目录结构

```
IcebearMailbox/
├── index.html          页面入口
├── css/style.css       样式（信封、火漆、邮戳、读信浮层）
├── js/
│   ├── app.js          渲染信件列表 / 恋爱计时 / 读信浮层
│   ├── envelope.js     拆信动画时序
│   └── particles.js    暖色光斑与火漆碎裂粒子
├── data/letters.js     ★ 你唯一需要编辑的文件
└── letters/            信件扫描件
```

## 将来部署给她

- **Vercel / Netlify**（推荐）：免费，支持私有仓库，把整个文件夹拖进 https://vercel.com 或 https://app.netlify.com/drop 即可得到一个网址。内容不会公开在代码库里。
- **GitHub Pages**：免费稳定，但免费版要求仓库公开，任何拿到链接的人都能翻到源码和图片，私密情书不太推荐（除非付费开启私有 Pages）。

## 将来升级「动态版」

现在她只能读你写的信。将来如果想让她也能回信、你在手机上直接发信，
只需要把 `data/letters.js` 换成一个返回同样结构的接口（后端随意选），
页面代码一行都不用改。
